# 🔁 Number Reversal and Digit Counter in C++
This is a simple C++ console application that takes an integer input from the user and outputs the reversed number along with the total number of digits. It uses basic concepts of modulus and division operations to reverse the digits and count them. Ideal for beginners learning loops, conditionals, and basic I/O in C++.
## 📌 Overview
This project was developed as part of foundational C++ practice to enhance understanding of digit manipulation and basic control structures.
This C++ project is a beginner-friendly console application that:
1- Reverses a user-entered integer number.
2- Calculates and displays the total number of digits in the number.
It demonstrates the use of loops, arithmetic operations, and basic input/output in C++.

## 🧠 How It Works
1. The program prompts the user to enter an integer.
2. It extracts each digit from the end using the modulus operator `%`.
3. It builds the reversed number by multiplying the current reversed value by 10 and adding the new digit.
4. The loop continues until all digits are processed.
5. It also counts the number of digits during the loop.


## 💡 Example

**Input:**
Enter a number: 1234

**Output:**
Reversed number is = 4321
Number of digits = 4

## 🛠️ Concepts Used
1- Loops (`while`)
2- Arithmetic operators (`%`, `/`)
3- Variables and input/output (`cin`, `cout`)
4- Integer manipulation
